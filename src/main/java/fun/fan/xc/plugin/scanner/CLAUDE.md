# 注解扫描模块 (scanner)

## 模块职责

注解扫描模块提供了自定义注解扫描功能，允许开发者通过注解方式定义扫描规则和处理逻辑。

## 核心组件

### 1. 启动注解
- `@XcScan`: 注解扫描启动注解，用于配置扫描规则

### 2. 核心类
- `XcScannerConfig`: 扫描器配置类
- `XcScannerConsumer`: 扫描结果处理器接口

## 核心功能

### 1. 自定义注解扫描
- 支持通过`@XcScan`注解配置扫描规则
- 支持指定扫描的包路径
- 支持定义匹配规则和处理逻辑

## 使用方式

1. 在Spring Boot启动类上添加`@XcScan`注解
2. 配置需要扫描的包路径和匹配规则
3. 实现`XcScannerConsumer`接口处理扫描结果

## 依赖模块

- 无特定依赖模块
