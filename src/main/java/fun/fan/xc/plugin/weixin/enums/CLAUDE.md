# 微信枚举类模块 (fun.fan.xc.plugin.weixin.enums)

## 模块职责

该模块包含了微信开发中使用的所有枚举类，用于定义微信API中的各种常量和状态。

## 核心组件

### 语言枚举
- `LangEnum`: 语言枚举，定义了微信支持的语言类型

### 错误码枚举
- `ErrorCodeEnum`: 错误码枚举，定义了微信API返回的错误码及其含义

### 小程序相关枚举
- `MPVersionEnum`: 小程序版本枚举，定义了小程序的版本类型
- `MiniProgramStateEnum`: 小程序状态枚举，定义了小程序的状态

## 关键文件

### 语言枚举
- `LangEnum.kt`: 语言枚举类，包含以下值：
  - `zh_CN`: 简体中文
  - `zh_TW`: 繁体中文
  - `en`: 英文

### 错误码枚举
- `ErrorCodeEnum.kt`: 错误码枚举类，定义了常见的微信API错误码，如：
  - `-1`: 系统繁忙
  - `0`: 请求成功
  - `40001`: 获取access_token时AppSecret错误
  - `40002`: 不合法的凭证类型
  - `40003`: 不合法的OpenID
  - 等等...

### 小程序相关枚举
- `MPVersionEnum.kt`: 小程序版本枚举类，包含以下值：
  - `Develop`: 开发版
  - `Trial`: 体验版
  - `Formal`: 正式版

- `MiniProgramStateEnum.kt`: 小程序状态枚举类，包含以下值：
  - `developer`: 开发版
  - `trial`: 体验版
  - `formal`: 正式版

## 接口规范

所有枚举类都遵循以下规范：
1. 使用Kotlin枚举类实现
2. 提供清晰的枚举值注释说明
3. 遵循微信官方文档的命名规范
4. 提供获取枚举值和描述的方法

## 依赖关系

### 内部依赖
- `fun.fan.xc.plugin.weixin`: 微信插件包

## 测试要点

1. 枚举值的正确性测试
2. 枚举值与描述的映射测试
3. 边界值和异常值测试

## 编码规范

1. 遵循Kotlin枚举类语法
2. 提供完整的枚举值注释
3. 使用大写字母和下划线命名枚举值
4. 保持与微信官方文档的一致性
