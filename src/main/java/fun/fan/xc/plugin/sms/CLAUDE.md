# 短信验证码模块 (sms)

## 模块职责

短信验证码模块提供了短信验证码的生成、存储和校验功能。该模块基于Redis实现验证码的存储和管理，支持频率限制和发送次数限制。

## 核心组件

### 1. 核心类
- `SMSCodeUtils`: 短信验证码工具类，提供验证码的生成和校验功能

### 2. 配置类
- `SendSettings`: 发送设置类，用于配置验证码的发送规则

## 核心功能

### 1. 短信验证码生成
- 生成6位随机数字验证码
- 支持自定义业务类型
- 支持配置发送频率限制（默认60秒一次）
- 支持配置验证码有效期（默认10分钟）
- 支持配置发送次数限制（默认1小时5次）

### 2. 短信验证码校验
- 校验用户输入的验证码是否正确
- 验证通过后自动清除验证码和频率限制

## 使用方式

1. 通过依赖注入使用`SMSCodeUtils`类
2. 调用`generateSMSCode`方法生成验证码
3. 调用`verifySMSCode`方法校验验证码

## 依赖模块

- `fun.fan.xc.plugin.redis`: 用于验证码的存储和管理
