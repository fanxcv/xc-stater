# 工具类模块 (fun.fan.xc.starter.utils)

## 模块职责

该模块提供了项目开发中常用的工具类，包括网络请求、加密解密、数据转换、集合操作等。

## 核心组件

### 网络工具类
- `NetUtils`: 网络请求工具类，封装了HTTP请求功能

### 加密工具类
- `EncryptUtils`: 加密解密工具类，提供各种加密算法实现

### 转换工具类
- `Conversion`: 数据转换工具类，提供类型转换功能
- `MapTools`: Map操作工具类，提供Map相关操作

### 集合工具类
- `XcCollections`: 集合操作工具类，扩展集合处理功能

### 通用工具类
- `Tools`: 通用工具类，提供常用工具方法

## 关键文件

### 网络工具类
- `NetUtils.kt`: 网络请求工具类，提供了以下功能：
  - HTTP GET/POST/PUT/DELETE请求
  - 请求参数构建
  - 响应结果解析
  - SSL支持
  - 超时配置
  - 请求头设置

### 加密工具类
- `EncryptUtils.kt`: 加密解密工具类，提供了以下功能：
  - MD5加密
  - SHA加密
  - AES加密解密
  - RSA加密解密
  - Base64编码解码
  - HMAC签名

### 转换工具类
- `Conversion.kt`: 数据转换工具类，提供了以下功能：
  - 基本数据类型转换
  - 字符串与数字转换
  - 日期格式转换
  - JSON转换

- `MapTools.kt`: Map操作工具类，提供了以下功能：
  - Map合并
  - Map过滤
  - Map转换
  - 嵌套Map操作

### 集合工具类
- `XcCollections.kt`: 集合操作工具类，提供了以下功能：
  - 集合过滤
  - 集合转换
  - 集合分组
  - 集合排序
  - 空安全操作

### 通用工具类
- `Tools.kt`: 通用工具类，提供了以下功能：
  - 字符串处理
  - 日期时间处理
  - 随机数生成
  - 路径处理
  - 系统属性获取

## 接口规范

### 工具类使用规范
1. 提供静态方法便于调用
2. 实现空安全检查
3. 提供详细的异常处理
4. 支持链式调用
5. 保持方法的无副作用性

## 依赖关系

### 外部依赖
- `FastJSON2`: JSON处理
- `Hutool`: 工具类库
- `Guava`: Google工具库
- `Bouncy Castle`: 加密算法库

### 内部依赖
- `fun.fan.xc.starter`: 核心启动模块
